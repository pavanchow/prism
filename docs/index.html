Prism

A software rasterizer in Rust. It draws real 3D triangles on the CPU, readable end to end, with a framebuffer, a z-buffer, and barycentric math doing all the work.

View on GitHub How it works

How it works

Four steps turn a list of triangles into pixels on screen, no dependencies beyond a CLI parser.

1

Transform

Vertices move through model, view, and projection matrices, written by hand, down to perspective divide.

2

Rasterize

Each triangle's bounding box is scanned, and barycentric coordinates decide which pixels fall inside it.

3

Depth test

A z-buffer keeps the nearest surface at every pixel, so triangles behind others are correctly hidden.

4

Shade

A directional light and a face normal set flat per-triangle brightness with one dot product.

5

Output

The finished framebuffer is written as binary PPM, a format simple enough to need no image crate.

6

Command line

One command renders the built-in demo scene to a file, with the output size configurable.

Try it

Render the demo scene to a PPM image with a single command.

cargo run -- render -o out.ppm --width 800 --height 600
