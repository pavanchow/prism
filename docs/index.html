Triangles into pixels,

Prism is a software rasterizer in Rust that draws real 3D triangles on the CPU. A framebuffer, a z-buffer, and barycentric math do all the work. Here is the real thing, running in your browser.

Speed

How it works

Six steps turn a list of triangles into pixels, with no dependency beyond a CLI parser.

1

Transform

Vertices move through model, view, and projection matrices written by hand, down to the perspective divide.

2

Rasterize

Each triangle's bounding box is scanned, and barycentric coordinates decide which pixels fall inside.

3

Depth test

A z-buffer keeps the nearest surface at every pixel, so triangles behind others are hidden correctly.

4

Shade

A directional light and a face normal set flat per-triangle brightness with a single dot product.

5

Output

The finished framebuffer is written as binary PPM, a format simple enough to need no image crate.

6

Command line

One command renders the built-in demo scene to a file, with the output size configurable.

Render from the command line.

The same pipeline you just dragged, writing a PPM image to disk.

# render the demo scene at 800x600
cargo run -- render -o out.ppm --width 800 --height 600
